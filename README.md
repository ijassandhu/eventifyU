#eventifyU

eventifyU is a web platform designed for Chandigarh Group of Colleges Landran to streamline the organization and management of events for the college and its various clubs. The platform allows students to create accounts, view upcoming and past events, check event attendance, and get details like time and venue. This project aims to eliminate the need for classroom announcements and make it easier for students to enroll in events that interest them.

#Features:
User Accounts: Students can create and manage their own accounts.
Event Listings: View all upcoming and past events in a centralized location.
Event Details: Check the time, venue, and attendance for each event.
Enrollment: Students can easily enroll in events they are interested in.
Club Management: Different clubs within the college can organize and manage their events.


#Technologies Used:
Frontend: React.js
Backend: Express.js, Node.js
Database: PostgreSQL
